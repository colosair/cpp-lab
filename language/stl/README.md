# STL

코딩테스트에 자주 쓰는 표준 라이브러리를 주제별로 실습하는 공간입니다.

- 대상: `vector`, `string`, `pair`/`tuple`, `map`/`set`, `unordered_map`, `queue`/`stack`/`priority_queue`, `<algorithm>`
- 파일 이름은 다루는 컨테이너나 알고리즘으로 짓습니다. 예: `vector.cpp`, `sort-and-search.cpp`
- 각 파일은 `main()`을 포함하고 단독으로 컴파일되도록 작성합니다.

아직 작성된 실습 파일은 없습니다.
