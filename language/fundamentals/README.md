# Fundamentals

C++ 기본 문법을 주제별 단일 파일로 실습하는 공간입니다.

- 대상: 변수와 타입, 제어문, 함수, 참조와 포인터, 클래스, 입출력
- 파일 이름은 주제를 드러내도록 짓습니다. 예: `references.cpp`, `class-basics.cpp`
- 각 파일은 `main()`을 포함하고 단독으로 컴파일되도록 작성합니다.

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic references.cpp -o references.exe      # Windows
clang++ -std=c++17 -Wall -Wextra -Wpedantic references.cpp -o references.out  # macOS
```

아직 작성된 실습 파일은 없습니다.
